# CLAUDE.md — Static Hebrew Charity Website Template

## Project Overview
Build a static HTML/CSS/JS website for an Israeli nonprofit/charity organization.
Language: Hebrew. Direction: RTL (full). Style: Professional, clean, emotional.
Zero backend — runs on GitHub Pages, cPanel, or any static host.
Filtered-internet compatible (Netspark / Rimon / Netiv / Etrog).

---

## Tech Stack

| Layer | Choice | Reason |
|---|---|---|
| Pages | Static HTML + CSS + JS | No server needed, filtered-internet safe |
| Admin | `/admin/index.html` (password protected) | Client self-management without CMS |
| Images/Video | Cloudinary unsigned upload | Client-side upload, no server |
| Forms | Formspree endpoint | Email delivery, no server, free tier |
| Donations | External link (Matara.pro / Nedarim Plus) | Israeli payment standard |
| Hosting | GitHub Pages (recommended) or cPanel | GitHub Pages = free + auto-deploy |
| RTL | Native `dir="rtl"` on `<html>` + Heebo font local | No Google Fonts CDN |

## Admin Panel — Features

### Authentication
- SHA-256 password hashed in localStorage
- First visit: set password (no default)
- Session persists via sessionStorage

### GitHub Token (for Save)
- Stored in localStorage (`shoreshim_admin_pat`)
- Falls back to `%%ADMIN_PAT%%` (injected by GitHub Actions at deploy)
- Status badge shows ✓/✗ in Account Settings
- UI in Account Settings card to paste and save token

### Split-Screen Live Preview
- Right panel: edit form (460px)
- Left panel: live site in `<iframe>`
- Each section header has an eye "אתר" button → scrolls preview + flashes gold highlight
- Typing in hero/about text fields updates preview in real-time via `postMessage`
- Mobile: tabs toggle between form and preview

### Editable Sections
| Section | Fields |
|---|---|
| Hero | Title, accent text, subtitle, video thumbnail image, YouTube URL |
| About/Mission | Body text, image, video (YouTube URL + thumbnail) |
| Services (3 tabs) | Image per tab (workshops / coaching / resilience) |
| Team | Dynamic list: name, role, bio, photo per member |
| Events/Conferences | Dynamic list: title, link, poster image |
| Testimonials | Dynamic list: quote, body, author, role, photo |
| Stats | 4 numbers + 4 labels + optional auto-fetch URL (Google Sheets JSON etc.) |
| Contact | Phone, WhatsApp, email |
| Contact Form | Formspree endpoint |
| Donations | Matara.pro / Nedarim Plus URL |

### Save Flow
1. Admin clicks "שמירה ופרסום"
2. Reads PAT from `%%ADMIN_PAT%%` or localStorage
3. Fetches SHA of each file from GitHub API
4. PUTs updated content to 4 files: `config.json`, `config.js`, `content.json`, `content.js`
5. If Matara URL changed → PUTs updated `donate.html` too
6. GitHub Actions deploys to GitHub Pages (~2 min)

## GitHub Actions Deploy (`.github/workflows/deploy.yml`)

Required secrets (set once in repo Settings → Secrets → Actions):
- `ADMIN_PAT` — GitHub fine-grained token, contents:write on this repo
- `CLD_CLOUD` — Cloudinary cloud name
- `CLD_PRESET` — Cloudinary unsigned upload preset

The workflow replaces placeholders in `admin/index.html`:
```
%%ADMIN_PAT%%  →  actual token
%%CLD_CLOUD%%  →  cloud name
%%CLD_PRESET%% →  preset name
```

## Cloudinary Upload (Media)

- Used for: hero thumbnail, about image/video thumbnail, service images,
  team photos, event posters, testimonial photos
- Upload widget: drag-and-drop zone + URL paste bar
- `handleFileChange(input, urlId, previewId)` — uploads to Cloudinary, sets URL field + preview
- Falls back gracefully if `CLD_CLOUD === '%%CLD_CLOUD%%'` (shows error)

## RTL Rules

```css
html { direction: rtl; }
body { text-align: right; font-family: 'Heebo', 'Assistant', Arial Hebrew, Arial, sans-serif; }
/* Flex containers: row-reverse is default in RTL — no need to override */
/* Form inputs: direction:rtl already inherited */
/* URL/phone fields: add dir="ltr" inline */
```

Heebo font loaded locally (no CDN) — copy WOFF2 files to `/fonts/` and use `@font-face`.

## postMessage API (Admin ↔ Preview)

Admin sends → iframe receives (same origin: github.io):

| type | payload | effect |
|---|---|---|
| `scroll-to` | `{id: 'hero'}` | smooth scroll + gold flash outline |
| `update-text` | `{id: 'content-hero-title', value: '...'}` | live DOM text update |

Receiver in `index.html` checks `e.origin === 'https://nir5177.github.io'` (update per project).

## Variables to Replace Per Client

```
REPLACE_ORG_NAME      → Organization name in Hebrew
REPLACE_PHONE         → Phone (055-XXXXXXX)
REPLACE_EMAIL         → contact@domain.org.il
REPLACE_WHATSAPP      → 972XXXXXXXXX (international, no +)
REPLACE_DONATE_URL    → https://matara.pro/... or similar
REPLACE_REPO_OWNER    → GitHub username
REPLACE_REPO_NAME     → GitHub repo name
REPLACE_SITE_ORIGIN   → https://USERNAME.github.io (for postMessage origin check)
REPLACE_COLOR_PRIMARY → #hex (navy)
REPLACE_COLOR_GOLD    → #hex (gold accent)
```

In admin/index.html:
```javascript
var REPO_OWNER  = 'REPLACE_REPO_OWNER';
var REPO_NAME   = 'REPLACE_REPO_NAME';
var REPO_BRANCH = 'gh-pages';
```

In index.html postMessage listener:
```javascript
if (e.origin !== 'REPLACE_SITE_ORIGIN') return;
```
